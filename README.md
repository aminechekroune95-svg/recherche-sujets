# Données collectées

Branche remplie automatiquement par GitHub Actions (workflow « Collecte des sujets et publication »).

- `lists.json` : pages de listes ccbac.fr et lignes par sujet
- `details/` : fiches brutes des sujets
- `texts/` : texte extrait des PDF
- `state.json` : avancement

Sujets : ministère de l Éducation nationale, Banque nationale de sujets, licence CC BY-NC-SA 3.0 FR.
